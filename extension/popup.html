How it works

A .pdf address or a filename ending in .pdf in the tab title starts the timer automatically. Switching tabs or leaving Edge pauses it.

Edge shows a debugging banner while this extension sends keyboard events. Canceling the banner turns autosave off.

This extension requests Ctrl+S through the browser. Edge’s PDF viewer may ignore it. A request is not confirmation that your file was saved.
